# Vitrine Alegre 🛒✨

Repositório GitHub: https://github.com/gibara98/VitrineAlegre
Site publicado (Vercel): https://vitrine-alegre-cqxs.vercel.app/
Front-end de e-commerce desenvolvido em **React** com o auxílio de IA, consumindo a API pública **DummyJSON** e construído fielmente a partir dos mockups da especificação técnica.

---

## 🚀 Extensão Escolhida (Seção 4.3)
Além do deploy obrigatório na Vercel (com o arquivo `vercel.json` configurado para o tratamento de rotas SPA / F5), escolhemos a seguinte extensão:
* **Carrinho no `localStorage`**: O estado do carrinho de compras persiste mesmo após atualizar a página ou fechar o navegador.

---

## 🛠️ Como rodar o projeto localmente

Siga os passos abaixo para clonar e rodar a aplicação na sua máquina:

```bash
# 1. Clone o repositório
git clone [https://github.com/gibara98/VitrineAlegre.git](https://github.com/gibara98/VitrineAlegre.git)

# 2. Entre na pasta do projeto
cd VitrineAlegre

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
